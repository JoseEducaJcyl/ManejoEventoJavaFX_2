# ManejoEventoJavaFX_2

Proyecto desarrollado en Java utilizando JavaFX y Maven para profundizar en el manejo de eventos en interfaces gráficas de usuario.

## Descripción

Esta aplicación es una continuación de prácticas de JavaFX centradas en el manejo de eventos, permitiendo la interacción con distintos componentes gráficos como botones y controles de la interfaz.

El objetivo es reforzar la comprensión de cómo se gestionan las acciones del usuario dentro de una aplicación de escritorio JavaFX mediante eventos.

## Tecnologías utilizadas

- Java
- JavaFX
- Maven

## Requisitos

- JDK 17 o superior
- Maven instalado
- IDE compatible con JavaFX (IntelliJ IDEA, Eclipse o NetBeans)
